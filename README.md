# First Sip Café – Interactive Coffee Shop Animation

## About
An interactive animation project developed using C++ and OpenGL. It tells the story of Sarah's visit to First Sip Café through four scenes, featuring animated characters, a 3D coffee cup, steam effects, background music, and sound effects.

## Technologies
* C++
* OpenGL
* FreeGLUT
* GLU
* WinMM for audio playback

## Features
* Display four scenes showing Sarah's visit to the café.
* Draw front and back views of a character.
* Move the character using the arrow keys.
* Display a 3D coffee cup.
* Animate steam rising from the coffee.
* Play background café music.
* Play a doorbell sound effect.
* Display story text in each scene.
* Use textured backgrounds for different scenes.

## Controls
* **1:** Display Scene 1.
* **2:** Display Scene 2.
* **3:** Display Scene 3.
* **4:** Display Scene 4.
* **Arrow Keys:** Move the character.
* **C:** Display the coffee cup in Scene 3.
* **S:** Play the doorbell sound in Scene 1.
